История проекта

AEMP — независимый проект по разработке музыкального программного обеспечения. Автор проекта — Артём Еремеев.

Наши платформы

Windows — настольная версия AEMP.

Наша цель

Развивать собственные аудиотехнологии, улучшать интерфейс и создавать удобные музыкальные приложения.
