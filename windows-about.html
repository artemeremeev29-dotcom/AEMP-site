О программе

AEMP Windows — настольная версия музыкального медиаплеера проекта AEMP, разработанного Артёмом Еремеевым.

Проект создаётся с целью предоставить пользователям удобный инструмент для прослушивания музыки на компьютере.

AEMP развивается как независимый проект. Его оформление и функциональность постепенно совершенствуются.
